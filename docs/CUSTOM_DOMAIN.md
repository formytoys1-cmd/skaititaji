# Подключение своего домена (например, nodod.lv)

Код уже готов: `PUBLIC_BASE_URL` имеет приоритет над авто-URL Render во всех
местах (ссылки в письмах верификации, QR-коды, self-ping). Менять код не
нужно — только DNS и одну переменную окружения.

## Шаг 1 — Купить домен
Рекомендованный вариант (проверено whois, свободен): **`nodod.lv`**
(«nodod» = повелительная форма «подай» — легко запоминается и сразу понятно
действие: «nodod rādījumus» = «подай показания»).

Регистраторы в Латвии:
- **NIC.LV** (официальный реестр .lv) — https://www.nic.lv
- Любой аккредитованный реселлер (Mikrotik.lv, Hostinger, Namecheap для .lv и т.д.)

Альтернативы, если nodod.lv займут (тоже свободны на момент проверки):
`radijums.lv`, `nodods.lv`, `uzradi.lv`, `skaititaja.lv`, `manaradijumi.lv`.

## Шаг 2 — Добавить домен в Render
1. Render Dashboard → сервис `skaititaji` → **Settings → Custom Domains**.
2. **Add Custom Domain** → ввести `nodod.lv` (и отдельно `www.nodod.lv`, если
   нужен www-редирект).
3. Render покажет DNS-записи, которые нужно добавить у регистратора:
   - Для apex-домена (`nodod.lv`): **A-запись** на IP Render (или ALIAS/ANAME,
     если регистратор поддерживает — уточнит Render в интерфейсе).
   - Для `www.nodod.lv`: **CNAME** → `skaititaji-xxxx.onrender.com`.
4. Render автоматически выпускает бесплатный SSL-сертификат (Let's Encrypt)
   после подтверждения DNS — обычно 5–30 минут после прописывания записей.

## Шаг 3 — Обновить переменную окружения
В Render → **Environment**:
```
PUBLIC_BASE_URL=https://nodod.lv
```
Это единственная переменная, которую нужно поменять в приложении. Она уже
используется для:
- ссылок в письмах подтверждения e-mail (`app/config.py:76`);
- self-ping keep-alive (`app/main.py:40`, чтобы free-инстанс не засыпал);
- определения production-режима, если `RENDER_EXTERNAL_URL` не задан явно.

## Шаг 4 — Проверить
```bash
curl -I https://nodod.lv/api/health
# ожидаем: HTTP/2 200, {"status":"ok",...}
```
Проверить, что QR-коды и ссылка в письме верификации показывают новый домен
(а не `onrender.com`) — открыть `/koplietosana` и зарегистрировать тестовый
аккаунт.

## Шаг 5 — Редирект со старого адреса (опционально)
Старый `skaititaji.onrender.com` можно оставить рабочим (он всегда будет
доступен как fallback Render) — переучивать пользователей не обязательно,
можно держать оба адреса одновременно. Редирект onrender→свой домен не
требуется технически (Render обслуживает оба хоста на одном сервисе).

## Итого
- Правки кода: **не требуются**.
- Правки окружения: **1 переменная** (`PUBLIC_BASE_URL`).
- Правки DNS: 1–2 записи у регистратора домена.
- Время: покупка домена — сразу; DNS propagation — от 5 минут до нескольких
  часов (обычно быстро для .lv через NIC.LV).
