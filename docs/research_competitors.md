- ✅ История платежей

- ✅ **«Mājas lieta»** (Домовое дело): электронная документация дома, категории с фильтрацией, push-уведомления о новых документах
- ✅ SMS-рассылка управляющим для срочных уведомлений

- ✅ Вход через **eParaksts mobile** (упомянут в changelog приложения: "Iespēja autorizēties ar eParaksts mobile")
- ✅ График потребления счётчиков (диаграммы)

### UX-поток передачи показаний счётчика (детально)

На основе публичного демо-портала (demo.webnams.lv, логин: demo@demo.lv / demo123) и описаний Apple App Store:

1. **Регистрация:** Жилец регистрируется самостоятельно через e-mail **или** управляющий создаёт аккаунт и высылает приглашение. Для регистрации нужны данные с квитанции (номер лицевого счёта / адрес). Ссылка для подтверждения приходит по email.
2. **Вход:** Email + пароль. Опционально: eParaksts mobile, биометрия в мобильном приложении, PIN.
3. **Экран счётчиков:** Список всех счётчиков квартиры (по типу: ХВС, ГВС, электричество и т.д.). Отображается **предыдущее показание** и дата его сдачи. Система показывает карточку каждого счётчика.
4. **Ввод показания:** Жилец вводит новое числовое значение в поле. Система автоматически рассчитывает потребление (разница).
5. **Валидация:** Если новое показание меньше предыдущего или выглядит аномально, система показывает предупреждение (упомянут "bugfix: скатитяя карточка, если новое совпадает с предыдущим").
6. **Подтверждение:** Показание сохраняется. Данные **автоматически импортируются в расчётную систему Nams** — не требуется ручного ввода.
7. **Уведомление:** Управляющий получает уведомление. При вибрации телефона — опция отключения (changelog: "Iespēja atslēgt vibrāciju rādījuma ievades laikā").

### 🔓 Аутентификация
**Ни одна из активных платформ не поддерживает Smart-ID** — де-факто стандарт аутентификации в Прибалтике (используется в государственных порталах, банках, Latvija.lv). Добавление Smart-ID и банковской аутентификации (через латвийские банки: Swedbank, SEB, Luminor, Citadele) сразу создаёт конкурентное преимущество.

### 🛡️ UX-надёжность
WebNAMS приложение хронически нестабильно (многочисленные отзывы «белый экран»). Стабильное, надёжное приложение — само по себе ценность.

### 📱 Мобильный опыт
В 2025/26 году мобильное приложение должно быть на уровне банковского: Face ID / Touch ID, мгновенные push-уведомления, offline-режим, плавная анимация.

### 🤖 Автоматизация показаний
Ни одна платформа не предлагает **фото-сканирование показаний через камеру** (OCR). Жилец просто фотографирует счётчик — система сама распознаёт цифры.

### 🌍 Мультиязычность
WebNAMS поддерживает RU — важно для Латвии. Bill.me и RNP портал — только LV/EN. **Полноценный RU-язык** — значимый фактор в латвийском контексте.

### 💬 Коммуникация
«Прямая саизна» у Bill.me — это конкурентный аргумент. Конкурирующий продукт должен иметь полноценный встроенный мессенджер с тикетами, статусами, приоритетами и фото.

### 🔌 Открытое API
Ни одна платформа не упоминает открытый API. SaaS с REST API для интеграций с Visma Horizon, 1C, и любым ERP — это сильное B2B предложение.

### 💰 Прозрачное ценообразование
WebNAMS (доминирующий игрок) скрывает цены. Bill.me показывает 1,20 € для потребителей. **Прозрачная ценовая страница с тарифами per-building/per-unit** снижает барьер входа для новых управляющих.

### 📊 Аналитика для управляющих
Ни одна платформа не предлагает управляющему **дашборд**: сколько показаний уже сданы, сколько нет, отклонения потребления по квартирам, должники. Это ценнейший инструмент для управляющего.
