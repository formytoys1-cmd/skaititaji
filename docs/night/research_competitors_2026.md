## 7. Анализ по UX-паттернам форм подачи показаний

### Поля формы (реконструкция по доступным данным)
На основе логики e-Pārvaldnieks и e-Saimnieks типичная форма включает:

| Поле | Описание |
|------|----------|
| Объект (dropdown) | Выбор адреса/квартиры из привязанных |
| Счётчик (dropdown/список) | ГВС / ХВС / Электричество |
| Серийный номер | Предзаполнен из БД (read-only) |
| Предыдущее показание | Read-only (из последней записи) |
| Текущее показание | Числовое поле (главный input) |
| Расход | Авторасчёт: текущее − предыдущее |
| Дата снятия | По умолчанию — сегодня |
| Фото (опционально) | Upload/camera |

### UX-паттерны, которые работают
1. **Временной баннер** — яркий banner сообщает «сдавай с 25 по 28» — снижает число ошибок «забыл»
2. **Предзаполнение предыдущего значения** — пользователь видит, что было, и вводит только новое
3. **Real-time расчёт потребления** — сразу показывает δ = текущее − предыдущее
4. **Disabled submit** до принятия условий
5. **Роль-зависимый интерфейс** — гость видит только подачу, собственник — полный функционал
6. **Firebase push** — напоминания прямо на телефон

## 9. ТОП-10 Конкретных рекомендаций для проекта «Skaitītāji»

### 🔴 Высокий приоритет

**1. Временной коридор подачи с баннером-напоминанием**
> Реализовать: показывать яркий баннер/alert на главной странице жителя в период с 20 по 30 число каждого месяца. За пределами периода — показывать статус «окно закрыто» с датой следующего. Источник: e-Pārvaldnieks.lv `/meters` баннер.

```html
<!-- Tailwind пример -->
<div class="bg-amber-100 border-l-4 border-amber-500 p-4 mb-4">
  <p class="font-semibold">📅 Показания принимаются с <strong>25 по 28</strong> числа.</p>
  <p class="text-sm text-amber-700">Осталось 3 дня до конца периода.</p>
</div>
```

**2. Трёхъязычный интерфейс: LV / RU / EN с первого дня**
> e-Pārvaldnieks получает жалобы в App Store именно из-за отсутствия русского языка — это незанятая ниша. e-Saimnieks уже имеет все три языка. В FastAPI + Jinja2: использовать `flask-babel` или `python-i18n`, переключатель языка в header, хранить предпочтение в сессии/cookie. Источник: отзыв App Store «I will come back, when you will add Russian language!»

**3. Паттерн «Было → Стало → Расход» с inline-расчётом**
> При вводе нового показания сразу показывать вычисленный расход (JavaScript `oninput`). Если расход аномальный (>N м³) — показывать предупреждение. Если текущее < предыдущего — блокировать submit с ошибкой. Источник: стандарт рынка.

```javascript
// Inline-расчёт расхода
document.getElementById('new_value').addEventListener('input', function() {
    const prev = parseFloat(document.getElementById('prev_value').value);
    const curr = parseFloat(this.value);
    const diff = (curr - prev).toFixed(3);
    document.getElementById('consumption').textContent = diff > 0 ? `+${diff} м³` : '⚠️ Значение меньше предыдущего';
});
```

**4. Email + SMS напоминания за 3–5 дней до закрытия окна**
> В e-Pārvaldnieks ToS прямо прописано право отправлять напоминания. Реализовать: Celery Beat задача, проверяет кто не подал за N дней до дедлайна → отправляет email (и опционально SMS через Twilio/Mailsms.lv). Источник: e-Pārvaldnieks ToS п.11.

**5. Мультитенантность + роли (управляющий / собственник / арендатор)**
> У e-Pārvaldnieks есть Īpašnieks и Īrnieks с разным набором прав, у e-Saimnieks — клиент и управляющий. В FastAPI: middleware проверки роли, отдельные Jinja2-шаблоны или блоки `{% if user.role == 'manager' %}`. Источник: оба конкурента.

### 🟠 Средний приоритет

**6. Real-time валидация пароля при регистрации**
> e-Saimnieks показывает 5 критериев в реальном времени с подсветкой ✓/✗. Простая реализация через Alpine.js или vanilla JS. Повышает конверсию регистрации и снижает ошибки. Источник: e-Saimnieks `/registration` HTML.

**7. PWA с manifest.json и возможностью установки на телефон**
> Оба конкурента имеют manifest.json и apple-touch-icon. Добавьте в FastAPI: `/manifest.json` endpoint, service worker для offline-кэширования страницы подачи. Это даёт «мобильное приложение» без затрат на App Store. Источник: оба конкурента — `manifest.json`, `theme-color` meta.

**8. Видимое поле «Срок поверки счётчика» (dēr.līdz)**
> Ни один из изученных открытых порталов не показывает это поле явно на форме (возможно, оно внутри за логином). Это ваша возможность дифференцироваться: добавить поле `verification_due` в модель счётчика и показывать предупреждение «Срок поверки истекает через 30 дней» — управляющий и житель сразу видят это. Соответствует нормативному требованию.

**9. Графики потребления по месяцам (история)**
