# Архитектура: main-чат + автономный форк-агент

Документ описывает, как устроена параллельная работа над проектом «Skaitītāji»:
основной чат (`main`) и автономный агент-форк, слушающий консоль обратной связи,
а также безопасный авто-мердж, который может инициировать кто угодно.

## Роли и ветки

| Участник | Где работает | Git-ветка | Рабочее дерево |
|----------|--------------|-----------|----------------|
| **Main-чат** (вы + агент) | этот чат | `main` | основной репозиторий |
| **Форк-агент** (автономный) | фоновый агент | `agent/console` | git worktree `../skaititaji-console-agent` |
| **Пользователи** | боевая консоль `/admin/inbox` | — (через команды) | — |

**Render** авто-деплоит только из `main`. Значит изменения форк-агента попадают
в прод **только после мерджа** `agent/console → main` — это встроенная защита.

### Почему git worktree
`git worktree` даёт форк-агенту отдельную рабочую директорию на ветке
`agent/console`, параллельно с `main`. Так основной чат и форк не мешают друг
другу (не конфликтуют по индексу/HEAD), но работают в одном репозитории и легко
обмениваются коммитами через ветки.

```
/Users/.../Web_Skaititaju_nodoshana        → main        (main-чат)
/Users/.../skaititaji-console-agent          → agent/console (форк-агент)
```

## Поток работы форк-агента

1. Слушает боевую консоль через защищённый agent-API (`/agent/api`).
2. Получив указание/баг от модератора — реализует в своём worktree на
   `agent/console`.
3. Прогоняет локальные гейты (импорт, a11y), коммитит и пушит `agent/console`.
4. Отвечает в консоль и при готовности инициирует авто-мердж.

## Авто-мердж (безопасный, CI-гейтед)

Мердж `agent/console → main` выполняет **GitHub Actions** (`automerge.yml`) с
обязательными проверками. Мердж происходит **только если гейты зелёные**:

- `import app.main` (приложение поднимается);
- a11y-гейт WCAG 2.2 AA (`tools/audit/a11y.mjs`);
- PWA smoke (`tools/audit/pwa_check.py` — манифест/SW/офлайн/иконки).

Кто может инициировать мердж:

| Инициатор | Как |
|-----------|-----|
| **Расписание (автономно)** | workflow `automerge` запускается сам **каждые 6 часов** и сливает `agent/console → main`, если ветка опережает main и гейты зелёные. Ничего запрашивать не нужно. |
| **Main-чат / вы** | вручную запустить workflow `automerge` (UI Actions → Run workflow) или `python -m tools.automerge agent/console --push` |
| **Форк-агент** | вызывает тот же workflow через API после своих проверок |
| **Пользователь из консоли** | пишет в консоли команду `[merge]` или `[merge agent/console]` — мост `console-control.yml` раз в 10 мин находит команду и запускает `automerge` |

После мерджа в `main` Render автоматически деплоит прод.

**Guard от лишней нагрузки:** если ветка не опережает main, запланированный
запуск пропускает гейты и мердж (быстрый выход) — CI не грузится вхолостую.

## Компоненты

| Файл | Назначение |
|------|------------|
| `tools/automerge.py` | локальный безопасный мердж ветки в main (гейт + git merge + push) |
| `.github/workflows/automerge.yml` | CI-мердж с гейтами (a11y, PWA), запуск вручную/по dispatch |
| `tools/console_control.py` | мост: команды `[merge]` из консоли → запуск `automerge` |
| `.github/workflows/console-control.yml` | опрос консоли на команды (каждые 10 мин) |
| `tools/audit/pwa_check.py` | PWA smoke-тест (устанавливаемость приложения) |
| `tools/agent_watch_live.py` | «сторож» консоли (уведомляет агента о новых сообщениях) |
| `tools/agent_remote.py` | удалённый CLI консоли (чтение/ответы агента) |

## Безопасность

- Прод-деплой — только из `main`, только через CI-гейтед мердж.
- Секрет `AGENT_API_KEY` — в GitHub Secrets и на Render; в код не коммитится.
- Все автослияния проходят те же ворота качества, что и обычные PR.
- Конфликты мерджа не заливаются: workflow/`automerge.py` прерывается и просит
  ручное разрешение.

## Быстрые команды

```bash
# создать/обновить worktree форк-агента
git worktree add ../skaititaji-console-agent agent/console

# локальный мердж (main-чат), с пушем
GH_PUSH_TOKEN=<token> python -m tools.automerge agent/console --push

# PWA smoke локально
python tools/audit/pwa_check.py http://127.0.0.1:8000
```
