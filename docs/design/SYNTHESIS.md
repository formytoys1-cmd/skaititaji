# Синтез: что применяем из 3 статей о веб-дизайне

Источники (полные отчёты рядом): [Shopify](research_shopify.md) · [Hostinger](research_hostinger.md) · [MailerLite](research_mailerlite.md).

Отобрано по критерию: **высокий impact + уместно для utility-SaaS** (не e-commerce),
без ущерба доступности (у нас 0 нарушений axe).

## ✅ Применяем (реализовано)
| Улучшение | Источник | Почему |
|---|---|---|
| Favicon (SVG-капля) | Hostinger QW-1 | Профессиональный вид, доверие |
| Open Graph + canonical | Hostinger QW-6, MailerLite #12 | Корректный шаринг ссылки, SEO |
| `<label for>` в форме входа | все три | WCAG 1.3.1 |
| Явные метки полей показаний | MailerLite #13 | WCAG 1.3.1, ясность |
| Таблицы: `scope`, `<caption>` | Hostinger QW-3 | Доступность для скринридеров |
| `role=progressbar` на прогрессе | Hostinger QW-4 | WCAG 4.1.2 |
| Защита от двойного сабмита | Hostinger QW-5 | UX, целостность данных |
| Иерархия CTA на лендинге | все три | Ясность «первичное действие» |
| Тач-таргеты 44px | Shopify П13, Hostinger QW-15 | Мобайл, WCAG 2.5.8 |
| Баннер объявлений (дедлайн подачи) | Shopify П12 | Снижает нагрузку на поддержку |
| Явный статус окна подачи в кабинете | MailerLite #3 | Житель сразу видит «можно ли подавать» |
| Полоса доверия (WCAG/GDPR/Visma) | Shopify П8 (честно) | Trust без фейковых цифр |
| Кастомная 404 (3 языка) | Hostinger QW-7 | Удержание, вид |
| Декоративные эмодзи `aria-hidden` в таблицах | Hostinger QW-11 | Доступность |

## ⏭️ Осознанно НЕ делаем (или отдельная задача)
| Пункт | Причина |
|---|---|
| Прод-сборка Tailwind (вместо CDN) | Крупная задача; в дорожной карте QUALITY.md (ускорит LCP, строгий CSP) |
| Hero-иллюстрация/маскот | Декор, низкая ценность для utility |
| Веб-аналитика (GA и т.п.) | Противоречит нашей privacy-позиции (только необходимые cookie). При необходимости — только серверная privacy-friendly |
| Товарные галереи/корзина/апселлы | E-commerce-специфика, неприменимо |
| Фейковые «10 000+ клиентов» | Нечестно для демо; заменено на честную полосу стандартов |

## Заметка про мобильную навигацию
Отчёты предлагают hamburger. У нас nav на `flex-wrap` — горизонтального скролла нет
(подтверждено на 360px), поэтому оставляем адаптивный wrap, но улучшаем тач-таргеты.
