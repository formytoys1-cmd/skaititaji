# Включение GitHub Copilot coding agent — пошагово

Цель: чтобы задачи из веб-консоли обрабатывались **автономно в облаке 24/7**,
без запущенной локальной сессии. Это делается ОДИН раз на стороне GitHub.
Код-мост уже готов (`tools/inbox_to_issues.py` сам назначит issue на агента).

## Что это даёт
- Пишешь в консоль (`/admin/inbox`) → воркфлоу `inbox-to-issues` создаёт GitHub Issue
  → Issue автоматически назначается на бота `copilot-swe-agent` → он делает
  черновой Pull Request сам. Всё без твоего компьютера.

## Шаг 1. Платный план Copilot
Coding agent доступен на **любом платном плане**: Copilot **Pro / Pro+ / Max /
Business**. На бесплатном — недоступен.
- Проверить/оформить: https://github.com/settings/copilot
- Для Pro/Pro+/Max агент **включён по умолчанию**.

## Шаг 2. Убедиться, что агент включён для репозиториев
Профиль (правый верхний угол) → **Copilot** → **Settings** →
раздел «**Copilot coding agent**» (в личных настройках это переключатель
«включить/выключить в ваших репозиториях»).
- Должно быть **включено** для `formytoys1-cmd/skaititaji`.
- Ничего дополнительно назначать вручную не нужно.

Прямая ссылка на настройки: https://github.com/settings/copilot/features
(или .../copilot — раздел про cloud/coding agent).

## Шаг 3. Проверить, что бот стал назначаемым
```bash
GH=<твой_токен_с_scope_repo>
curl -s -H "Authorization: Bearer $GH" -H "Content-Type: application/json" \
  -X POST https://api.github.com/graphql \
  -d '{"query":"query{repository(owner:\"formytoys1-cmd\",name:\"skaititaji\"){suggestedActors(capabilities:[CAN_BE_ASSIGNED],first:20){nodes{login}}}}"}'
```
В ответе среди `nodes` должен появиться **`copilot-swe-agent`**.
Пока его нет — фича ещё не активна (или план не платный).

## Шаг 4. Готово — дальше автоматически
- `tools/inbox_to_issues.py` при каждом запуске (каждые 15 мин по расписанию)
  создаёт Issue из новых сообщений консоли и **сам назначает** их на агента,
  как только бот доступен. Никаких правок кода не требуется.
- Хочешь проверить сразу: Actions → `inbox-to-issues` → **Run workflow**.
- Отключить авто-назначение (если понадобится): переменная `ASSIGN_COPILOT=0`
  в окружении воркфлоу.

## Ручной способ (без консоли)
Любую issue можно отдать агенту вручную: открыть Issue → **Assignees** →
выбрать **Copilot**. Он возьмёт задачу и создаст черновой PR.

## Примечания / ограничения
- **Automations** (запуск агента по расписанию/событию самим GitHub) требуют,
  чтобы репозиторий был **private/internal** — в публичных недоступны. Наш мост
  `inbox-to-issues` этого не требует: он сам создаёт и назначает Issue.
- Черновой PR от агента проходит те же CI-гейты (tests/lint/security), что и
  обычные изменения — ничего не сольётся без прохождения проверок.
